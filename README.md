# 链动小铺缺货商品隐藏脚本

一个用于链动小铺商品页的油猴脚本。它会自动隐藏缺货商品，并修复隐藏后可能出现的列表空洞或瀑布流错位。

## 功能

- 自动识别 `.stock.rank0` 或状态文字为“缺货”的商品
- 兼容链动小铺的瀑布流卡片与纵向列表两种页面模板
- 点击“加载更多”后自动处理新增商品
- 窗口尺寸变化后自动重新排列瀑布流
- 仅在 `https://pay.ldxp.cn/shop/*` 页面运行
- 不读取账户数据，不保存浏览记录，不发送网络请求

## 安装

1. 安装 [Tampermonkey](https://www.tampermonkey.net/) 或其他兼容的用户脚本管理器。
2. 打开仓库中的 [`ldxp-hide-out-of-stock.user.js`](./ldxp-hide-out-of-stock.user.js)。
3. 点击 GitHub 页面右上方的 **Raw**。
4. 在用户脚本管理器弹出的安装页面中确认安装。

如果脚本管理器没有自动弹出，也可以新建脚本，将文件内容完整粘贴进去并保存。

## 使用

安装后直接访问任意链动小铺店铺页面即可：

```text
https://pay.ldxp.cn/shop/*
```

脚本会在商品加载后自动隐藏缺货项，无需手动操作。

## 实现说明

链动小铺目前存在两套商品页面结构：

- 瀑布流模板：商品卡片使用 `.goods_item`
- 纵向列表模板：商品条目使用 `.goods-item`

脚本通过库存元素的 `rank0` 类名识别缺货状态，并以“缺货”文字作为后备判断。对于绝对定位的瀑布流页面，隐藏商品后会重新计算可售商品的位置和容器高度；普通列表页面则交给浏览器自然回流。

`MutationObserver` 会监听动态加载的商品，因此“加载更多”产生的新项目也会立即处理。

## 权限与隐私

脚本使用：

```javascript
// @grant none
```

它仅修改当前页面的商品展示，不访问其他网站、不收集数据，也不会执行购买或登录操作。

## 兼容性

建议使用近期版本的 Chrome、Edge 或 Firefox，并搭配最新版 Tampermonkey/Violentmonkey。

## 注意事项

本项目是针对第三方网页结构编写的非官方脚本。如果链动小铺后续修改商品类名或库存标记，脚本可能需要同步更新。
